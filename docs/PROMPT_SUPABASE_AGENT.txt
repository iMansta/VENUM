========================================================
PASSO 1: VERIFICAR MAPEAMENTO DE IDs
========================================================

Antes de executar o schema, execute estas queries para verificar o mapeamento:

```sql
select id from auth.users limit 1;
select id from public.profiles limit 1;
```

- Se os IDs forem IGUAIS (padrão Supabase): O schema está correto
- Se os IDs forem DIFERENTES: Ajuste todas as foreign keys de auth.users para public.profiles

========================================================
PASSO 2: EXECUTAR SCHEMA SQL COMPLETO
========================================================

Execute o arquivo completo: supabase/schema.sql

Este SQL cria:
- Tabela missions com coluna end_date
- Tabela mission_participants
- Tabela transports (corrigida com quantity, status CHECK, created_by, reserved_at)
- Tabela guild_codes
- RLS Policies para todas as tabelas
- Índices para performance
- Funções RPC: get_weekly_ranking, get_monthly_ranking, get_user_ranking_position
- Funções RPC: award_points, deduct_points, validate_guild_code

========================================================
PASSO 3: CRIAR BUCKET DE STORAGE
========================================================

1. Acesse Storage no painel Supabase
2. Clique em "Create a new bucket"
3. Nome: avatars
4. Marque como Public
5. Clique em "Create bucket"

========================================================
PASSO 4: CONFIGURAR POLICIES DO STORAGE
========================================================

No bucket avatars, crie estas policies:

Policy 1: Public Read Access
- Allowed Operation: SELECT
- Target Roles: anon, authenticated
- Policy Definition: true

Policy 2: Authenticated Upload
- Allowed Operation: INSERT
- Target Roles: authenticated
- Policy Definition: auth.role() = 'authenticated'

========================================================
PASSO 6: AJUSTE SE NECESSÁRIO (SE IDs FOREM DIFERENTES)
========================================================

Se profiles.id != auth.users.id, execute:

```sql
-- Ajustar foreign keys em missions
ALTER TABLE public.missions DROP CONSTRAINT missions_created_by_fkey;
ALTER TABLE public.missions ADD CONSTRAINT missions_created_by_fkey 
  FOREIGN KEY (created_by) REFERENCES public.profiles(id) ON DELETE SET NULL;

-- Ajustar foreign keys em transports
ALTER TABLE public.transports DROP CONSTRAINT transports_reserved_by_fkey;
ALTER TABLE public.transports ADD CONSTRAINT transports_reserved_by_fkey 
  FOREIGN KEY (reserved_by) REFERENCES public.profiles(id) ON DELETE SET NULL;

ALTER TABLE public.transports DROP CONSTRAINT transports_created_by_fkey;
ALTER TABLE public.transports ADD CONSTRAINT transports_created_by_fkey 
  FOREIGN KEY (created_by) REFERENCES public.profiles(id) ON DELETE SET NULL;
```
